# VGA32SGemul

---

Sega SG-1000 Emulator for FabGL cards
---

This is an Sega SG-1000 emulator for ESP32 systems compatible with FabGL/VGA32.

Installation and usage:

- [Sega SG-1000](https://minibots.wordpress.com/2026/09/07/emulador-de-sega-sg-1000-con-lilygo-ttgo-vga32/)

Tested on:

- [Lilygo TTgo VGA32](https://minibots.wordpress.com/2024/06/08/lilygo-ttgo-vga32/)

- [Olimex ESP32-SBC-FabGL](https://minibots.wordpress.com/2026/07/08/olimex-esp32-sbc-fabgl/)

## Origin

Based on the emulator [Sega SC-3000](https://minibots.wordpress.com/2026/07/19/emulador-de-sega-sc-3000-con-lilygo-ttgo-vga32/).

### Changes made to the original involve:

- Reduced RAM from 2 KB to 1 KB.

- Definition of keys on PS/2 keyboard to simulate controllers.

- IPP and Matrix Keyboard deployment is removed.
